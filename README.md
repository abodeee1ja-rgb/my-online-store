# سوقنا: سوق مصغّر متعدد البائعين

كل بائع يسجّل ويفتح متجره ويضيف منتجاته (بصور) ويستلم طلباته. الزبون يتصفح ويطلب (دفع عند الاستلام).
الواجهة عربية RTL ومصممة للموبايل أولاً، وتنثبّت على الشاشة الرئيسية كأنها تطبيق (PWA).

## التشغيل

```bash
pip install flask
python app.py
```

افتح http://127.0.0.1:5000. لتجربته من الموبايل (نفس الشبكة): افتح `http://<عنوان IP جهازك>:5000`.

## شنو بيه

**الزبون**: تصفح وبحث وفلترة بالفئات، صفحة متجر، سلة، إتمام طلب (يشتري بدون حساب أو بحساب)، طلباتي.
إذا طلب من عدة متاجر ينفتح طلب منفصل لكل متجر.

**البائع**: فتح متجر، إضافة/تعديل/حذف منتجات مع صور، متابعة المخزون، استلام الطلبات
(جديد ← مؤكد ← تم التسليم، أو إلغاء يرجّع الكمية للمخزون)، وملخص بالمبيعات.

**الأمان**: كلمات السر مشفّرة (hash)، حماية CSRF على كل النماذج، منع رفع ملفات غير الصور،
وكل بائع يشوف ويعدّل منتجاته وطلباته فقط.

## تحويله لتطبيق

1. **PWA (جاهز هسه)**: بعد ما ترفعه على سيرفر بـ HTTPS، من Chrome على الأندرويد: ⋮ ← «تثبيت التطبيق».
   على الآيفون: مشاركة ← «إضافة إلى الشاشة الرئيسية».
2. **تطبيق أندرويد للمتجر (APK/AAB)**: ارفع الموقع على HTTPS ثم استخدم
   [PWABuilder](https://www.pwabuilder.com) أو Bubblewrap لتغليفه كتطبيق، أو Capacitor إذا تريد WebView.
3. **تطبيق أصلي بالكامل (Flutter / React Native)**: الـ API جاهز:

| المسار | الوصف |
|---|---|
| `GET /api/products?q=&category=&store=&limit=` | بحث وقائمة المنتجات |
| `GET /api/products/<id>` | تفاصيل منتج |
| `GET /api/stores` | المتاجر |
| `GET /api/categories` | الفئات |

حالياً الـ API للقراءة فقط (تصفح). لما تبني تطبيق أصلي تحتاج تضيف مسارات JSON لتسجيل الدخول والطلبات.

## قبل النشر الحقيقي

- شغّله بـ `gunicorn -w 2 app:app` خلف Nginx مع شهادة HTTPS (Let's Encrypt)، وما تستخدم `app.run`.
- عيّن `SECRET_KEY` كمتغير بيئة (أو يتولد ملف `secret.key` تلقائياً، لا ترفعه لـ git).
- خذ نسخة احتياطية دورية من `market.db` ومجلد `static/uploads/`.
- أضف `SESSION_COOKIE_SECURE = True` و`SESSION_COOKIE_SAMESITE = "Lax"` عند تشغيله على HTTPS.
- الدفع حالياً عند الاستلام فقط. الدفع الإلكتروني (زين كاش، كي كارد...) يحتاج تكامل مع مزوّد الخدمة.

## الملفات

```
app.py          الخادم: المسارات وقاعدة البيانات (SQLite) والـ API
templates/      الصفحات (جينجا)
static/         التنسيق، manifest.json، sw.js، الأيقونات، uploads/ (صور المنتجات)
```
